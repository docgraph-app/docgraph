# Security

If you find a security problem in DocGraph, **please don't open a public issue.**

Email **support@docgraph.app** with "Security" in the subject line. Include:

- the DocGraph version and your platform,
- what an attacker could do, and
- the steps to reproduce it.

We aim to reply within a week. Once a fix ships, we'll credit you in the
release notes if you'd like.

This covers the DocGraph app, its update mechanism, and the Claude Code plugin in
this repository. For the open-source plugin SDK and registry, use the same address.
